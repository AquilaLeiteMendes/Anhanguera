## 💡 Sobre o Projeto

O diret��rio `LINGUAGEM DE PROGRAMAÇÃO` foi criado para registrar exercícios e projetos acadêmicos desenvolvidos em Python. O objetivo principal é aplicar conceitos aprendidos em sala de aula para resolver problemas reais de forma organizada, legível e funcional.

Ao longo do desenvolvimento, foram criados exemplos que demonstram o uso de:

- listas e dicionários;
- funções reutilizáveis;
- entrada e saída de dados;
- tratamento de erros;
- persistência em arquivos JSON;
- gráficos com `matplotlib`;
- lógica de negócio para sistemas simples.

## ✨ Atividades Incluídas

### 1) Sistema de Gerenciamento de Livros

Arquivo: `SISTEMA_DE_GERENCIAMENTO_DE_LIVROS.ipynb`

Este notebook implementa uma biblioteca digital com as seguintes funcionalidades:

- [x] Cadastro de livros
- [x] Listagem de todos os títulos cadastrados
- [x] Busca por título parcial
- [x] Salvamento em arquivo JSON
- [x] Carregamento de dados salvos
- [x] Geração de gráfico por gênero literário

A aplicação foi pensada para simular um sistema simples de gestão de acervo em uma biblioteca, com foco em organização, armazenamento e visualização de dados.

### 2) Sistema de Gestão de Notas de Alunos

Arquivo: `Sistemas_de_Gestão_de_Notas_de_Alunos.ipynb`

Neste projeto, o aluno pode:

- [x] Inserir várias notas
- [x] Validar entrada numérica
- [x] Calcular a média final
- [x] Definir a situação do aluno (Aprovado/Reprovado)
- [x] Exibir um relatório final com as notas e a média

Esse exercício reforça o uso de funções, validação de dados e lógica condicional em Python.

## 🚀 Como Executar

### Opção 1: Google Colab

1. Abra o Google Colab.
2. Faça upload do notebook desejado.
3. Execute as células em sequência.

### Opção 2: Jupyter Notebook local

1. Clone o repositório:

```bash
git clone https://github.com/AquilaLeiteMendes/Anhanguera.git
```

2. Acesse a pasta do projeto:

```bash
cd Anhanguera
cd "LINGUAGEM DE PROGRAMAÇÃO"
```

3. Inicie o Jupyter:

```bash
jupyter notebook
```

4. Abra o notebook desejado e execute as células.
